# 問題: 月次レポートの自動作成（初級）

## 背景

店舗向け管理画面で、前月の売上レポートを毎月作り、担当者がダウンロードできるようにする。完成したら担当者に知らせる。

## 要件

- 管理画面は App Service。売上明細は Azure SQL に保存済み
- 店舗は 300 店舗。レポートは店舗別 CSV で、作成は数十分かかってよい
- 失敗した店舗だけ再作成できること。過去 12 か月のファイルを保管する
- 候補は Functions の定期実行、Container Apps Jobs、Blob Storage、Service Bus、Azure SQL

## 設問

1. 売上明細、生成した CSV、生成状態をそれぞれどこに保存するか。RDB と Blob Storage の役割を説明せよ。
2. 毎月の処理開始から各店舗の CSV 作成、完了通知までの流れを示せ。
3. Functions と Container Apps Jobs のどちらで CSV を作るか。処理時間と店舗ごとの再実行を基準に選べ。
4. 1 店舗の処理が失敗しても、他店舗のレポートを完成させる方法を述べよ。

## ヒント

- 300 店舗を1回の処理でまとめる必要はあるか
- ファイルの保存先と、ダウンロード画面に表示する状態は別々に考えられる
