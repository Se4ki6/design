# 問題: 写真投稿と縮小画像の作成（初級）

## 背景

地域イベントの写真投稿サイトを作る。利用者が写真と説明文を送ると投稿を受け付け、後から一覧表示用の縮小画像を作る。

## 要件

- 投稿画面と API は App Service で動かす。画像は最大 20 MB、1 日 2,000 枚
- 投稿直後は「処理中」と表示してよい。縮小画像は 5 分以内に作る
- 投稿者、説明文、公開状態、投稿日時で検索する
- 画像の変換が失敗しても、元画像は残し、再処理できること
- 候補は Azure SQL、Cosmos DB、Blob Storage、Event Grid、Functions

## 設問

1. 元画像、縮小画像、投稿情報をどこに保存するか。RDB・NoSQL・Blob Storage の用途を比較して選べ。
2. アップロードから縮小画像の完成までの流れを示せ。Event Grid と Functions に何を担当させるか。
3. 一覧画面には処理中・公開中・失敗の状態をどう表示するか。状態はどこに保存するか。
4. 同じ画像作成イベントが2回届いても、縮小画像や投稿が重複しない方法を説明せよ。

## ヒント

- 画像本体と検索に使う項目では、適した保存形式が異なる
- イベントに画像本体を載せる必要があるか
